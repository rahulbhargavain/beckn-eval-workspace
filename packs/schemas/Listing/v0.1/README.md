# Listing v0.1

Filterable facts for a tourism listing. Name, place description and media belong in the Descriptor.

Status: experimental, workspace-owned, not an upstream Beckn schema (UNVERIFIED against beckn/schemas and beckn/DEG).

The schema is structural only. Required fields and controlled value lists are enforced by the network policy (`packs/policies/`), per the schema design guide. Vocabulary mappings in `vocab.jsonld` are provisional.
